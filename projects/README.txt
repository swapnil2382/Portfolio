Screenshots for the featured project showcase.
==============================================

Drop your real screenshots in this folder, then point to them from
src/pages/Page4.jsx -> featuredProjects[].screenshot

Example:
    screenshot: "/projects/fintech.png"

(The leading slash matters. Files in /public are served from the site root.)

WHAT TO CAPTURE
---------------
Web apps    -> browser window, ~1600x1000, the most interesting screen
               (a dashboard beats a login page)
Mobile apps -> phone screenshot, portrait, ~1080x2340

Blur or replace any client / personal data before saving.

Until a screenshot is set, the frame draws a generated UI skeleton,
so the section looks intentional either way.
